# 旋转公约数

浏览器数字空间推理小游戏。打开 index.html 即可离线运行。

- 低、中、高难度分别使用 5×5、6×6、7×7 盘面
- 点击四格中心旋钮，周围数字顺时针旋转 90°
- 各类别全部数字上下左右连通即通关
- 支持撤销、重置、分类提示、参考答案和慢速自动解答

自动解答为演示模式，非最少步数解法。

## 难度设置

- 低难度：3类，除数5、7、11，轻度打乱，默认显示分类，保留完整类别和较大的连通块。
- 中难度：6类，除数在50—100之间，中度分散，默认隐藏分类。
- 高难度：7类，除数在100—200之间，充分打散，每类至少分成4块，默认隐藏分类。

出题按实际连通块数量和最大连通块占比筛选。难度是按盘面特征分级，并非最少解题步数的数学证明。所有题均从已解盘旋转生成，保留合法复原路径。
